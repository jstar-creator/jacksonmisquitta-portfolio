# Jackson Misquitta — Portfolio

A responsive portfolio for video editing, motion graphics and independent software tools for creative workflows.

## Live site

The site is deployed with Cloudflare Pages.

## Deploy with Cloudflare Pages

- Production branch: `main`
- Framework preset: `None`
- Build command: `exit 0`
- Build output directory: `public`

## Project notes

The featured software projects are works in progress. Their descriptions reflect current concepts and development direction; they should not be read as claims of completed releases.

## Updating the site

- Edit `public/index.html` for copy, project descriptions and links.
- Edit `public/style.css` for visual styling and responsive layouts.
- Edit `public/script.js` for small client-side enhancements.

Update the contact email and project links in `public/index.html` if they change.
