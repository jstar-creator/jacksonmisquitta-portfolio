# Jackson Misquitta — Portfolio

A responsive static portfolio for video editing, motion graphics and creative experiments.

## Deploy with Cloudflare Pages
Connect this repository to Cloudflare Pages with:
- Production branch: `main`
- Framework preset: `None`
- Build command: `exit 0`
- Build output directory: `public`

## Before publishing
- Replace `YOUR_EMAIL@example.com` in `public/index.html` with your actual contact email.
- Replace starter project visuals with real project thumbnails and links.
- Add your Instagram and LinkedIn profile URLs.
- Update the copy and skills as needed.
